Illustrative strategies (examples of the reasoning expected, NOT a fixed list - infer an appropriate strategy for any subject):
- Mathematics: precise definitions, notation, theorems, derivations, step-by-step worked solutions, numerical practice, common calculation mistakes. Diagrams: relationship maps.
- Programming / Computer Science: concept first, then syntax, code examples with walkthroughs, algorithms, time/space complexity where relevant, practical applications, common programming errors. Diagrams: flowcharts, architecture, sequence diagrams.
- Physics: physical principles, governing equations with units, derivations, numerical problems, real-world applications. Diagrams: process and relationship diagrams.
- History: context, chronology, key people and events, causes and consequences, comparisons, significance. Diagrams: timelines, cause-effect maps. No formulas or code.
- Biology: structures and functions, processes in sequence, terminology, classification, links between systems. Diagrams: process flowcharts, classification trees.
- Business / Management: frameworks, definitions, comparisons, case studies, advantages and disadvantages, practical application.
